Script -> Footage Studio (Chrome / Edge, Manifest V3)

INSTALL
1. Unzip.
2. chrome://extensions -> Developer mode ON -> Load unpacked -> pick the unzipped folder.
3. Click the extension icon: workspace opens.

FLOW
1. Workspace: Upload script (.txt) or Paste script. Format "1: text", "2: text" ... up to any number.
   Optional search words: "3: Entras a una farmacia | pharmacy shelves".
2. Open Pexels / Pixabay / Mixkit / Coverr / etc. Panel bottom-right shows active line, progress, total footage, live timer.
   Hover any video -> "Add to line N" button. File saves into extension storage, active line auto-advances.
   Any other site: right-click video -> "Send video to active script line".
3. Close laptop anytime. Reopen workspace -> Resume.
4. Settings: paste free Groq API key.
5. "Open video editor": footage already loaded. Add Spanish voiceover (Uploads tab), paste on-screen text (Sync tab), click Sync.
6. Export MP4 1080p (always original quality).

WHITE BACKGROUND + LOGO CUTOUT
Editor -> Uploads -> "+ White background (2.8s)". Drop or click a logo image so it overlaps that clip: tick "Remove background" in the Edit tab and it is removed (offline, first run takes ~15 s, later ones are instant). Edit tab -> tick "Remove background" (off by default) to remove it; untick for the original.
